## 角色与权限

门户包含管理员和普通用户两种角色。

| 页面或操作 | 管理员 | 普通用户 |
| --- | :---: | :---: |
| 系统总览 | 可访问 | 自动跳转到作业管理 |
| 用户、组、账户和集群用户 | 可管理 | 不可访问 |
| 分区、节点和权限 | 可管理 | 不可访问 |
| 查看活动及近期完成作业 | 可查看全部 | 可查看全部 |
| 查看作业详情 | 可查看 | 可查看 |
| 查看作业输出 | 任意作业 | 仅自己的作业 |
| 取消作业 | 任意作业 | 仅自己的作业 |
| 修改自己的密码 | 可操作 | 可操作 |

页面权限由门户控制，实际操作还取决于运行账户的 LDAP、Slurm 和文件系统权限。

## 登录与退出

### 登录

1. 在浏览器中打开管理员提供的 HTTPS 地址。
2. 输入 LDAP 用户名和密码。
3. 点击“登录”。

![登录界面](./login.png)

管理员登录后进入系统总览；普通用户进入作业管理。若登录失败，请先确认用户名、密码和门户地址，再联系管理员检查 LDAP 服务。

### 退出

点击侧边栏底部的“退出”。在共享电脑上使用后应主动退出，不要只关闭浏览器标签页。

## 界面与列表操作

### 导航

管理员侧边栏包含：

- 总览
- 用户管理
- 组管理
- 账户管理
- 集群用户
- 分区管理
- 作业管理
- 节点管理
- 权限管理

普通用户只显示作业管理、账户设置和外部系统入口。点击侧边栏底部的用户信息或“账户”，可进入密码修改页面。

### 表格

- 表头在纵向滚动时保持可见。
- 数字列右对齐，状态列居中，操作列固定在右侧。
- 宽表在内容超出容器时才显示横向滚动条。
- 用户列表支持搜索和点击表头排序。
- 键盘用户可以聚焦列表区域后使用方向键滚动。

页面显示“加载失败”时，先点击刷新按钮或刷新浏览器；持续失败再联系管理员。

## 系统总览

系统总览仅管理员可访问，集中展示 LDAP 用户、运行中和排队中作业、空闲节点，以及近期活动作业和分区状态。

![系统总览](./dashboard.png)

点击“刷新”重新获取数据；点击近期作业或分区区域的入口可进入对应管理页面。总览用于快速判断集群状态，具体配置和错误信息应在对应页面查看。

## 用户管理

用户管理维护 LDAP 用户，并展示与 Slurm 关联的计算额度和使用情况。

![用户管理](./user.png)

### 用户列表

列表包含用户名、UID、GID、家目录、存储配额、CPU 核时、GPU 卡时、Shell、所属组和状态。顶部搜索框可按用户名、UID、家目录或配额筛选。

每行提供以下操作：

- **报表**：按时间范围查看作业数量、状态、CPU 核时、GPU 卡时和运行时长，并可导出 CSV。
- **拨付**：增加或扣除 CPU 核时、GPU 卡时；负数表示扣除。
- **更多操作**：编辑用户、修改磁盘配额、生成或重置 SSH 密钥、禁用用户、删除用户。

### 创建用户

1. 点击“创建用户”。
2. 填写用户名、UID、主组、家目录和 Shell。
3. 根据需要填写初始密码和存储配额。
4. 需要授予门户管理权限时，勾选“授予管理员权限”。
5. 点击“创建”。

注意事项：

- 用户名、UID 必须唯一。
- 主组必须已经存在。
- 勾选“不限制”时，存储配额记为无限制。
- 创建成功后，系统会使用 `SLURM_DEFAULT_ACCOUNT` 建立对应的 Slurm 用户关联。
- 未配置 NFS 配额文件系统时，请保持“不限制”；显式设置配额需要先启用 NFS quota。

### 编辑和禁用用户

在“更多操作”中选择“编辑用户”，可修改显示名称、主组、家目录、Shell、密码和管理员身份。编辑自己的账户时不能撤销自己的管理员权限。

存储配额通过独立的“修改磁盘配额”操作维护。NFS quota 未启用时，该操作会单独报错，不影响 LDAP 用户资料的编辑。

“禁用用户”会将用户 Shell 设置为不可登录状态。禁用不会删除用户数据或历史作业。

### SSH 密钥

选择“生成 / 重置 SSH 密钥”后，系统会更新 LDAP 中的公钥并下载新的私钥。旧密钥随即失效。私钥只应交付给目标用户并妥善保存，不要通过公开聊天、工单或代码仓库传递。

### 删除用户

删除操作会移除 LDAP 用户及对应的 Slurm 关联，且不可撤销。操作前应确认：

- 用户没有需要保留的身份信息；
- 用户没有运行中或待处理作业；
- 家目录和业务数据已按本单位流程备份或移交。

门户不会自动删除用户家目录。

## 组管理

组管理页面显示 LDAP 组名、GID、成员数量、成员列表和描述。

### 创建组

1. 点击“创建组”。
2. 填写唯一的组名和 GID。
3. 可选填写描述。
4. 点击“创建”。

### 编辑或删除组

“编辑”可修改 GID 和描述；“删除”会删除 LDAP 组，但不会删除组内用户。删除前必须确认该组不是任何用户的主组，并评估对文件权限和 Slurm `AllowGroups` 的影响。

当前页面仅展示成员信息，不提供成员增删入口。需要调整成员时，请使用现有 LDAP 管理流程。

## Slurm 账户管理

账户管理页面维护 Slurm Account。

### 创建账户

点击“创建账户”，填写账户名，可选填写组织和描述，然后提交。账户名创建后不可在编辑页面修改。

### 编辑或删除账户

“编辑”可修改组织和描述。“删除”前应先检查该账户下的用户关联和作业策略；存在依赖时，Slurm 可能拒绝删除。

Slurm 账户不同于 LDAP 用户，也不同于门户管理员身份。

## 集群用户关联

“集群用户”页面维护 Slurm Association，即用户、账户、集群、分区和 QOS 之间的关系。

### 查看与筛选

使用“账户筛选”查看指定账户的关联。账户级关联会显示为“（账户级）”，不能按用户执行编辑、拨付或删除。

### 添加关联

1. 点击“添加关联”。
2. 填写用户名并选择账户。
3. 可选填写分区；留空表示全局关联。
4. 可选填写 QOS 列表和默认 QOS。
5. 点击“添加”。

### 编辑与拨付

“编辑”可调整 QOS 和默认 QOS。分区属于 Association 标识，创建后不能直接修改；如需更换分区，应新建目标分区关联，再确认并删除旧关联，原关联的历史用量不会迁移。“拨付”用于调整 CPU 核时和 GPU 卡时：正数增加，负数扣除。拨付时必须填写 Comment，建议包含项目、工单号或变更原因；该说明会写入 Slurm Association，并显示在关联列表中。提交前应核对用户、账户和分区，避免将额度写入错误的关联。

删除关联不会删除 LDAP 用户，但可能使用户无法在对应账户或分区提交作业。

## 分区管理

分区管理展示状态、节点总数、已分配/空闲/离线节点、最大时间和默认分区。配置文件路径显示在页面顶部。

### 创建和编辑分区

点击“创建分区”或行内“编辑”，按弹窗填写分区名称、节点范围、状态、最大时间、默认分区和访问限制等配置。

- 节点范围可使用 `node[01-08]` 或逗号分隔形式。
- `MaxTime` 可使用 `INFINITE` 或 Slurm 支持的时间格式。
- `AllowGroups` 使用英文逗号分隔多个组。

保存后系统写入 `/etc/slurm/partition.conf` 并执行 `scontrol reconfigure`。若配置内容无效或运行账户权限不足，操作会失败并保留错误信息。

### 删除分区

删除前确认分区内没有需要保留的运行中或排队作业，并确认该分区未被 Association、QOS 或提交脚本依赖。删除配置后系统会重新加载 Slurm 配置。

## 节点管理

节点管理展示节点名称、状态、CPU、内存、所属分区和 GRES。配置文件路径显示在页面顶部。

| 常见状态 | 含义 |
| --- | --- |
| `IDLE` | 空闲，可接收作业 |
| `ALLOC` / `ALLOCATED` | 资源已分配 |
| `MIXED` | 部分资源已分配 |
| `DRAIN` / `DRAINING` | 排空中，不接收新作业 |
| `DOWN` | 离线或故障 |

### 节点操作

- **下线**：将节点设为 Drain，不再接收新作业；现有作业通常继续运行。
- **上线**：执行 Resume，使已恢复的节点重新参与调度。
- **编辑**：修改节点配置。
- **删除**：从 `/etc/slurm/node.conf` 删除节点配置。
- **添加节点**：向节点配置文件写入新节点。

添加、编辑或删除后系统会重新加载 Slurm 配置。配置操作不等同于物理部署节点；`slurmd`、网络、DNS、Munge 和硬件资源仍需由集群运维人员配置。

## 作业管理

作业管理是所有登录用户都可以访问的页面。

![作业管理与作业详情](./job.png)

### 页面内容

页面顶部显示运行中、排队中、今日完成和今日失败数量。活动作业列表支持按分区和状态筛选；下方显示最近完成作业及退出码。

常见状态：

| 状态 | 含义 |
| --- | --- |
| `RUNNING` | 正在运行 |
| `PENDING` | 等待资源或调度条件 |
| `COMPLETED` | 正常完成 |
| `FAILED` | 执行失败 |
| `CANCELLED` | 已取消 |
| `TIMEOUT` | 超过时间限制 |
| `OUT_OF_MEMORY` | 超出内存限制 |

### 查看详情和输出

点击“详情”查看作业 ID、名称、用户、状态、分区、节点、工作目录以及标准输出/错误路径。路径可访问时，可以继续查看文件内容。

输出查看器支持手动刷新和按间隔自动刷新。为避免长时间请求，页面只读取受限范围和有限行数。普通用户只能读取自己的作业输出；管理员可以读取任意作业输出，但文件仍必须位于后端允许的目录中。

### 取消作业

点击活动作业右侧的“取消”并确认：

- 管理员可以取消任意作业；
- 普通用户只能取消自己的作业；
- 取消操作不可撤销，资源释放时间取决于 Slurm 状态更新。

门户用于查看和取消作业，不提供作业提交表单。

## 文件管理

所有登录用户都可以从侧边栏进入文件管理：

- 普通用户看到的 `/` 是自己的 LDAP `homeDirectory`，不能通过 `..` 或符号链接访问 Home 之外的路径；
- 管理员首次进入文件管理时打开自己的系统 Home，但仍可通过路径框和“上一级”访问服务器系统根目录 `/`，并以门户服务进程的 root 权限操作；
- 页面支持进入目录、直接输入路径、显示隐藏项目、上传和下载文件、新建目录、重命名及递归删除目录；
- “家目录”按钮可随时返回当前身份的个人 Home；普通用户返回页面映射的 `/`（LDAP Home），管理员返回 NSS/SSSD 为当前登录用户名解析出的系统 Home，无法解析时回退到 `/`；
- 大目录按 50、100 或 200 项分页加载，后端不会为了显示第一页一次性加载全部条目；
- 点击普通文件会打开带行号的统一在线编辑弹窗；编辑仅支持大小不超过 `FILE_EDIT_MAX_KB` 的 UTF-8 文本，二进制或超大文件应使用“下载”；
- 关闭存在未保存修改的编辑器时，页面会再次询问，可选择保存、不保存或继续编辑；
- 新建、重命名、删除和编辑均使用站内统一弹窗，不调用浏览器系统输入或确认组件；
- 上传默认不覆盖同名项目，单个文件大小由 `FILE_UPLOAD_MAX_MB` 控制；
- 删除操作不可恢复，删除目录时会同时删除其中的内容。

普通用户上传或新建的内容会尽量设置为其 LDAP UID/GID。若 LDAP Home 不存在、UID/GID 无效或底层文件系统拒绝操作，页面会显示相应错误。

## Web 终端

所有登录用户都可以从侧边栏进入 Web 终端。页面使用 xterm.js 连接后端伪终端，Shell 的身份始终是当前登录用户名对应的 Linux 系统账户。即使该用户同时是门户管理员，终端也优先进入其系统 Home，不会使用文件管理的系统根目录范围，也不会自动进入 `/root`。

- 点击侧边栏“Web 终端”文字会在当前页面进入终端；点击右侧的新标签图标会在新标签页打开终端，原页面保持不变；
- 页面打开后自动连接，也可以手动断开和重新连接；每次连接都会启动新的登录 Shell；
- 终端大小会随浏览器窗口自动调整，支持常用 ANSI 颜色和交互式程序；
- Ctrl/⌘+Shift+C 复制选择内容，Ctrl/⌘+Shift+V 粘贴；
- 点击终端标题栏的“收起”，终端会缩成右下角悬浮条，Shell 和 WebSocket 连接继续运行；点击“展开”恢复终端并重新适配窗口大小；
- 连接期间点击站内导航时，页面会询问如何处理：可以留在终端、在新标签打开目标页面并保留终端，或者断开 Shell 后离开；
- 刷新、关闭页签或通过地址栏离开时，浏览器会显示原生离开确认；确认离开、主动断开或超过配置的空闲时间后，后端会结束该 Shell；
- 终端不会继承门户后端的 LDAP 凭据、Session 密钥等环境变量。

管理员可在“账户设置 → 终端 AI 模型”中启用和配置 DeepSeek、vLLM、SGLang 或其他 OpenAI 兼容服务。vLLM、SGLang 和自定义服务需要填写 Base URL 和实际模型名称；DeepSeek 默认使用 `https://api.deepseek.com/v1`。API Key 保存后不会在页面回显，留空保存会保留原密钥，勾选“清除已保存的 API Key”才会删除。

终端上方会直接显示当前使用的模型。用户可以从服务商建议项中选择，也可以手动输入该 OpenAI 兼容服务实际提供的模型 ID，然后点击“应用”或按 Enter。该选择只覆盖当前终端连接，不会修改管理员的全局模型配置，也不会影响其他用户；切换模型会清除当前 AI 对话、目标及待确认动作，并关闭自动批准，Shell 会话保持不变。刷新、断开或重新连接后恢复管理员配置的默认模型。

启用 AI 后，终端按以下规则处理输入：

- 可识别的 Shell 命令照常直接执行；自然语言输入会发送给模型对话；
- 未安装命令、Shell 别名或集群自定义命令可能无法被自动识别，此时在命令前加 `!` 可强制按 Shell 命令执行，例如 `!cluster-status`；
- AI 返回的文字只显示在终端中。系统会围绕当前目标按“建议一个动作 → 执行 → 分析结果 → 建议下一动作”自动循环，直到模型判断目标完成或达到步骤上限；标题栏可把单次目标上限设置为 1–50 步，默认 10 步，设置在当前终端连接内保留；
- 默认采用人工批准模式：每个建议命令或文件动作都不会自动执行，必须先审阅，再按 **Ctrl+Enter** 确认；
- 标题栏可勾选“自动批准”。首次勾选会显示安全风险，确认后普通后续动作可自动执行；该设置只在当前终端连接内有效，取消勾选、“新对话”、断开或刷新页面都会关闭；
- 自动批准可能覆盖当前目录文件、提交作业、消耗 GPU/配额，并会把 AI 动作的终端输出发给模型服务。系统识别到 `sudo`、递归删除、取消作业、关机和磁盘操作等高危命令时，即使已启用自动批准也会暂停并要求 **Ctrl+Enter**；风险识别是附加保护，不能替代用户审阅和最小权限控制；
- AI 可建议创建脚本或文本文件：终端会先显示完整的文件写入操作，按 **Ctrl+Enter** 后才在当前 Shell 工作目录中写入；脚本可同时设置可执行权限；
- 执行后，命令仍在当前用户、当前工作目录的同一个 Shell 中运行；结束后系统将退出码和最多约 128 KiB 的近期输出交给模型分析，显示总结，并在目标未完成时给出下一动作；
- 命令行空闲时会显示“输入命令，或输入问题与 AI 对话…”淡色提示，开始输入后自动消失，不会成为 Shell 输入的一部分；
- AI 在当前终端连接内保留最近四轮对话上下文，并单独保留当前循环目标，避免多步执行后遗失原始要求；点击标题栏“新对话”会清除对话、循环目标和待确认命令，并关闭自动批准，但不会重启或退出当前 Shell；
- 使用方向键、Tab 补全等导致浏览器无法可靠还原当前命令行时，本次回车会直接交给 Shell，避免改变原有终端编辑行为；该行提交后会自动恢复 AI 分类，不会影响后续自然语言输入。

中文输入法提交或粘贴单行文本时，即使浏览器把文本和回车合并发送，终端也会先完成命令/自然语言分类。包含多行内容的粘贴仍按原生 Shell bracketed-paste 处理，不会把整段脚本误当成一条 AI 问题；需要强制执行不在系统 PATH 中的单行命令时，仍建议使用 `!命令`。

终端 AI 预设当前环境是 OpenHPC WebUI 管理的 Slurm 集群，当前 Shell 位于已认证用户的登录节点，因此不会要求用户重复提供调度器类型、登录节点、用户名或提交命令示例。模型会使用 Slurm 和系统的只读命令查询实际分区、节点、账户与资源配置；除 Slurm 和登录节点外，不预设任何集群拓扑或站点配置。复合目标会逐项完成，例如“检查集群、创建脚本、提交作业、读取输出并分析”不会在只创建脚本后结束。若模型只描述下一步、索要可查询的信息或遗漏结构化动作，后端会自动要求模型纠正一次；纠正后仍没有动作时会保留当前目标，等待用户补充，而不会显示为已完成。未明确要求性能压测时，生成的测试脚本应采用轻量操作，默认运行不超过 60 秒。

不同兼容模型对 JSON 协议的遵循程度可能不同。WebUI 能从“说明文字 + JSON”或 Markdown JSON 代码块中提取实际答复及文件/命令动作，也支持分段文本响应。模型把明确要执行的单个命令错误地放进独立 `bash`/`sh` 代码块时，WebUI 也会恢复为待确认动作；没有执行引导语的教学代码示例仍只作为文字显示。模型正文为空时会自动重试一次；第二次仍只有推理字段时，仅提取其中合法的动作 JSON、不显示推理过程，并强制人工确认该动作，即使已启用自动批准。连续两次没有可用内容时会提示切换模型。终端 AI 不会从分区名称推断资源类型，也不会预设节点名、GRES/TRES 名称、硬件厂商、软件模块或固定 Slurm 参数；涉及加速器等资源时，应以当前集群实际探测到的配置和工具为准。仅当用户明确要求 GPU 时，Slurm 作业脚本才会检查是否包含 GPU 资源申请。未经要求独占或占满节点、安装软件、修改系统配置、提升权限或执行磁盘压测都会受到提示词约束，其中可识别的高风险动作仍会强制人工确认。

模型服务会接收用户的自然语言问题，以及经用户确认的 AI 命令及其执行输出。请勿把密钥、个人数据或其他敏感内容提交给不受信任的外部模型服务。原始 Shell 命令不会因为启用 AI 而统一上传；只有自然语言对话和 AI 建议命令的结果会进入模型请求。

悬浮收缩只在当前页面内保持连接；它不会让 Shell 跨页面迁移。需要一边使用门户其他页面、一边保留终端时，应选择“新标签打开目标”，或者直接通过侧边栏右侧图标把终端开在独立标签页。

若提示系统账户未同步、Home 不存在、UID 与其他用户冲突或 Shell 不可执行，请让管理员检查 SSSD/NSS、LDAP `uidNumber`、`homeDirectory`、`loginShell` 和目录权限。每名用户必须使用唯一 UID。终端不可见时，管理员应确认生产环境启用了认证且 `TERMINAL_ENABLED=True`。

## 权限管理

权限管理仅管理员可访问。

### 授予管理员权限

1. 输入 LDAP 用户名，或点击“从 LDAP 加载用户列表”后选择用户。
2. 点击“授予管理员权限”。
3. 确认用户出现在当前管理员列表中。

### 撤销管理员权限

点击目标用户右侧的“撤销权限”。系统不允许当前登录管理员撤销自己的权限，避免意外失去管理入口。

管理员列表写入 `.env` 的 `ADMIN_USERS`，通过页面修改后立即生效。应至少保留一名确认可登录的管理员，并定期审计列表。

## 账户设置与修改密码

所有登录用户都可以修改自己的 LDAP 密码：

1. 点击侧边栏底部的账户入口。
2. 输入当前密码。
3. 输入并确认新密码。
4. 点击“保存修改”。

新密码不能与当前密码相同。修改成功后，后续登录及其他使用 LDAP 认证的系统会使用新密码。

## 常见问题

### 登录后看不到管理菜单

当前账户不是门户管理员。普通用户只能访问作业管理、账户设置和外部系统。需要管理权限时，请联系现有管理员授权。

### 页面没有数据或提示加载失败

先点击页面“刷新”并确认网络连接。若多个 Slurm 页面同时失败，通常是 Slurm 控制端、命令权限或门户后端异常；若只有 LDAP 页面失败，通常与 LDAP 连接或 Bind 配置有关。

### Web 终端页面正常但无法连接

若状态一直显示“连接中”或很快提示断开，管理员应检查浏览器开发者工具和门户日志中的 `/ws/terminal` 请求。通过 Nginx 部署时必须使用 HTTP/1.1，并转发 `Upgrade` 和 `Connection` 请求头。普通 HTTP `GET /ws/terminal` 返回 404 通常表示代理没有执行 WebSocket Upgrade；未登录的 WebSocket 握手返回 403 则是正常的认证拒绝。

连接到后端后仍失败时，再检查当前用户名能否通过 `getent passwd <用户名>` 唯一解析、Home 是否存在、登录 Shell 是否可执行，以及门户进程是否有权切换到对应 UID/GID。

### 作业一直处于 PENDING

在作业详情中检查原因，并核对分区状态、节点资源、QOS、Association 和作业请求。门户只展示 Slurm 返回的信息，不会自动修改排队条件。

### 无法查看作业输出

确认作业属于当前用户、输出路径存在且位于允许目录中。管理员还应检查 `JOB_OUTPUT_ALLOWED_ROOTS`、用户 Home 目录以及门户运行账户的文件读取权限。

### 创建用户后无法提交作业

在“集群用户”页面确认用户已关联到正确的 Slurm 账户、集群和分区，并检查 QOS。还应确认 LDAP 身份已同步到计算节点。

### 分区或节点配置保存失败

常见原因包括字段格式错误、配置文件不可写、Slurm 命令不可用或 `scontrol reconfigure` 失败。请停止重复提交，并由管理员查看应用与 Slurm 日志。

### 密码修改失败

确认当前密码正确、新密码两次输入一致，并检查 LDAP 是否允许该用户修改密码。认证关闭的本地调试模式不应用于生产环境。

## 获取帮助

报告问题时请提供：

- 发生问题的页面和操作；
- 页面提示的完整错误信息；
- 大致发生时间；
- 涉及的用户名、作业 ID、分区或节点名称；
- 可脱敏的截图。

不要在问题报告中包含密码、私钥、Session Cookie 或 LDAP 管理凭据。

## 术语表

| --- | --- |
