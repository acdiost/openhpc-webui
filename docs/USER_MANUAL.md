## 系统概述

### 什么是智算中心管理门户？

智算中心管理门户是一个为 HPC（高性能计算）中心设计的轻量级 Web 管理系统。通过这个系统，管理员可以方便地：

- 管理 LDAP 身份系统中的用户和组
- 管理 Slurm 集群的分区和计算节点
- 查看和管理正在运行的作业队列

### 主要功能

| 功能模块 | 描述 |
|---------|------|
| 仪表盘 | 展示用户数、作业数、节点状态等概览信息 |
| 用户管理 | 创建、修改、删除 LDAP 用户，自动同步到 Slurm |
| 组管理 | 管理用户组，添加或移除组成员 |
| 分区管理 | 管理 Slurm 计算分区，查看资源状态 |
| 节点监控 | 查看计算节点状态和资源占用 |
| 作业管理 | 查看和管理 Slurm 作业队列 |

### 系统要求

- 现代浏览器（Chrome、Firefox、Edge、Safari）
- LDAP 管理员账户
- 网络连接到服务器

## 登录系统

### 步骤 1: 打开登录页面

在浏览器地址栏输入系统地址，例如：

```
http://your-server-ip:6827
```

您将看到登录界面。

### 步骤 2: 输入登录凭据

1. **用户名**: 输入您的 LDAP 管理员用户名
2. **密码**: 输入您的 LDAP 管理员密码

### 步骤 3: 点击登录

点击"登录"按钮，系统将验证您的凭据。

**登录成功后**，您将被自动跳转到仪表盘页面。

**如果登录失败**，请检查：
- 用户名和密码是否正确
- LDAP 服务是否正常运行
- 网络连接是否正常

## 仪表盘

登录后，您将看到系统仪表盘，这是系统的主页。

### 仪表盘内容

仪表盘显示以下关键信息：

1. **用户总数**: 当前 LDAP 系统中的用户数量
2. **活动作业数**: 正在运行和排队中的 Slurm 作业数量
3. **节点状态**:
   - 空闲节点（Idle）
   - 分配中节点（Allocated）
   - 离线节点（Down）
4. **作业统计图表**: 不同状态作业的可视化分布

### 导航栏

左侧固定导航栏包含以下菜单项：

- **仪表盘** (首页)
- **用户管理**
- **组管理**
- **分区管理**
- **节点监控**
- **作业管理**
- **登出**

点击任意菜单项即可切换到对应功能页面。

## 用户管理

用户管理页面允许您管理 LDAP 系统中的所有用户。

### 查看用户列表

1. 点击左侧导航栏的"用户管理"
2. 系统将显示所有用户的列表

用户列表包含以下信息：
- **用户名** (uid)
- **UID** (用户ID)
- **GID** (组ID)
- **家目录** (Home)
- **Shell**
- **姓名** (CN)
- **操作按钮**

### 创建新用户

#### 步骤 1: 点击"添加用户"按钮

在用户列表页面右上角，点击"添加用户"按钮。

#### 步骤 2: 填写用户信息

在弹出的对话框中，填写以下必填信息：

- **用户名**: 英文字母和数字组合，例如 `dawn`
- **UID**: 用户ID，必须是唯一的数字，例如 `1001`
- **GID**: 主组ID，例如 `1000`
- **家目录**: 用户的主目录路径，例如 `/home/dawn`
- **Shell**: 默认 Shell，一般选择 `/bin/bash`
- **密码**: 用户的初始密码
- **姓名**: 用户的真实姓名（可选）

**重要提示**:
- UID 必须是唯一的，不能与现有用户重复
- 家目录建议遵循 `/home/用户名` 的格式

#### 步骤 3: 确认创建

点击"确认"按钮。系统将：
1. 在 LDAP 中创建用户
2. 自动在 Slurm 账户系统中添加该用户
3. 显示创建成功提示

创建完成后，新用户将出现在用户列表中。

### 编辑用户信息

#### 步骤 1: 找到要编辑的用户

在用户列表中找到需要修改的用户。

#### 步骤 2: 点击"编辑"按钮

点击该用户行右侧的"编辑"按钮。

#### 步骤 3: 修改信息

在弹出的对话框中，您可以修改：
- GID（主组ID）
- 家目录
- Shell
- 姓名
- 密码（留空表示不修改密码）

#### 步骤 4: 保存修改

点击"保存"按钮，修改将立即生效。

### 删除用户

#### 步骤 1: 找到要删除的用户

在用户列表中找到需要删除的用户。

#### 步骤 2: 点击"删除"按钮

点击该用户行右侧的"删除"按钮。

#### 步骤 3: 确认删除

系统会弹出确认对话框询问："确定要删除用户 XXX 吗？"

点击"确认删除"按钮。

#### 步骤 4: 删除完成

系统将：
1. 从 LDAP 中删除该用户
2. 从 Slurm 账户系统中删除该用户
3. 显示删除成功提示

**警告**: 删除操作不可撤销，请谨慎操作！

## 组管理

组管理页面允许您管理 LDAP 系统中的用户组。

### 查看组列表

1. 点击左侧导航栏的"组管理"
2. 系统将显示所有组的列表

组列表包含以下信息：
- **组名** (cn)
- **GID** (组ID)
- **描述**
- **成员列表**
- **操作按钮**

### 创建新组

#### 步骤 1: 点击"添加组"按钮

在组列表页面右上角，点击"添加组"按钮。

#### 步骤 2: 填写组信息

在弹出的对话框中，填写以下信息：

- **组名**: 英文字母和数字组合，例如 `research`
- **GID**: 组ID，必须是唯一的数字，例如 `2000`
- **描述**: 组的用途说明（可选），例如 "研究人员组"

#### 步骤 3: 确认创建

点击"确认"按钮，新组将被创建并显示在组列表中。

### 管理组成员

#### 添加成员

1. 在组列表中找到目标组
2. 点击该组的"添加成员"按钮
3. 在弹出的对话框中选择要添加的用户
4. 点击"确认"按钮

用户将被添加到该组，并在组的成员列表中显示。

#### 移除成员

1. 在组列表中找到目标组
2. 在该组的成员列表中，找到要移除的用户
3. 点击用户旁边的"移除"按钮
4. 在确认对话框中点击"确认"

用户将从该组中移除。

### 删除组

#### 步骤 1: 找到要删除的组

在组列表中找到需要删除的组。

#### 步骤 2: 点击"删除"按钮

点击该组行右侧的"删除"按钮。

#### 步骤 3: 确认删除

系统会弹出确认对话框询问："确定要删除组 XXX 吗？"

点击"确认删除"按钮。

**注意**:
- 删除组不会删除组内的用户
- 如果该组是某些用户的主组，可能无法删除

## 分区管理

分区管理页面允许您管理 Slurm 集群的计算分区。

### 查看分区列表

1. 点击左侧导航栏的"分区管理"
2. 系统将显示所有 Slurm 分区的列表

分区列表包含以下信息：
- **分区名称**
- **状态** (UP/DOWN)
- **节点列表**
- **总节点数 / 空闲节点数**
- **最大运行时间**
- **允许的组**
- **操作按钮**

### 查看分区详情

点击任意分区名称或"查看"按钮，可以查看该分区的详细信息：

- 分区配置参数
- 节点状态分布
- CPU 和内存使用情况
- 当前运行的作业

### 创建新分区

#### 步骤 1: 点击"创建分区"按钮

在分区列表页面右上角，点击"创建分区"按钮。

#### 步骤 2: 填写分区信息

在弹出的对话框中，填写以下信息：

- **分区名称**: 例如 `gpu-partition`
- **节点列表**: 用逗号分隔的节点名称，例如 `node01,node02,node03`
- **状态**: 选择 `UP`（启用）或 `DOWN`（禁用）
- **设为默认分区**: 勾选此项可将该分区设为默认分区
- **最大运行时间**: 可选，例如 `24:00:00`（24小时）
- **允许的组**: 可选，限制哪些组可以使用该分区

#### 步骤 3: 确认创建

点击"确认"按钮，新分区将被创建。

**注意**: 创建分区需要 Slurm 管理员权限。

### 修改分区

#### 步骤 1: 找到要修改的分区

在分区列表中找到目标分区。

#### 步骤 2: 点击"编辑"按钮

点击该分区行右侧的"编辑"按钮。

#### 步骤 3: 修改配置

您可以修改：
- 分区状态（UP/DOWN）
- 节点列表
- 最大运行时间
- 允许的组
- 是否为默认分区

#### 步骤 4: 保存修改

点击"保存"按钮，修改将立即生效。

### 启用/禁用分区

快速切换分区状态：

1. 在分区列表中找到目标分区
2. 点击"启用"或"禁用"按钮
3. 确认操作

**效果**:
- 禁用的分区不接受新作业提交
- 已运行的作业不受影响

### 删除分区

#### 步骤 1: 确保分区无运行作业

删除分区前，请确保：
- 分区内没有正在运行的作业
- 分区内没有排队的作业

#### 步骤 2: 点击"删除"按钮

在分区列表中找到目标分区，点击"删除"按钮。

#### 步骤 3: 确认删除

在确认对话框中点击"确认删除"。

**警告**: 删除分区前请务必确认无运行作业！

## 节点监控

节点监控页面允许您查看集群中所有计算节点的状态。

### 查看节点列表

1. 点击左侧导航栏的"节点监控"
2. 系统将显示所有计算节点的列表

节点列表包含以下信息：
- **节点名称**
- **状态** (Idle/Allocated/Mixed/Down)
- **分区**
- **CPU 总数 / 已分配数**
- **内存 总量 / 已分配量**
- **负载**
- **GRES**（GPU等资源）
- **操作按钮**

### 节点状态说明

| 状态 | 说明 |
|-----|------|
| Idle | 空闲，可接受新作业 |
| Allocated | 完全分配，所有资源被占用 |
| Mixed | 部分分配，还有剩余资源 |
| Down | 离线或故障 |
| Drain | 正在排空，不接受新作业 |
| Draining | 正在排空中，等待现有作业完成 |

### 按分区过滤

在页面顶部的下拉菜单中，选择特定分区可以只显示该分区的节点。

### 查看节点详情

点击任意节点名称或"详情"按钮，可以查看：

- 节点硬件配置（CPU、内存、GPU等）
- 当前运行的作业列表
- 资源使用情况图表
- 节点启动时间和运行时长

### 节点管理操作

#### 下线节点（Drain）

当需要维护或检修节点时：

1. 在节点列表中找到目标节点
2. 点击"下线"按钮
3. 输入下线原因，例如 "硬件维护"
4. 点击"确认"

**效果**:
- 节点不再接受新作业
- 现有作业继续运行直到完成
- 所有作业完成后，节点进入 Drain 状态

#### 恢复节点上线（Resume）

维护完成后，恢复节点：

1. 在节点列表中找到下线的节点
2. 点击"上线"按钮
3. 确认操作

**效果**:
- 节点恢复 Idle 状态
- 可以接受新作业

#### 强制设置节点为 Down

如果节点出现故障：

1. 找到故障节点
2. 点击"设为Down"按钮
3. 输入原因，例如 "硬件故障"
4. 确认操作

**效果**:
- 节点立即标记为 Down
- 节点上运行的作业会被取消或转移

在作业列表中找到目标作业。

#### 步骤 2: 点击"取消"按钮

点击该作业行右侧的"取消"按钮。

#### 步骤 3: 确认取消

系统会弹出确认对话框："确定要取消作业 XXXXX 吗？"

2. 释放该作业占用的资源

## 常见问题

### 1. 登录时提示"用户名或密码错误"

**可能原因**:
- LDAP 管理员密码不正确
- LDAP 服务未启动
- 网络连接问题

**解决方法**:
```bash
# 检查 LDAP 服务状态
sudo systemctl status slapd

# 测试 LDAP 连接
ldapsearch -x -H ldap://localhost:389 -D "cn=admin,dc=acdiost,dc=com" -w password
```

### 2. 创建用户时提示 UID 已存在

**原因**: 您输入的 UID 已被其他用户使用。

**解决方法**:
- 查看用户列表，找到未使用的 UID
- 通常从 1000 开始递增分配 UID

### 3. 删除用户时提示"删除失败"

**可能原因**:
- 用户仍有正在运行的作业
- 用户是某些组的唯一成员
- LDAP 权限不足

**解决方法**:
1. 检查该用户是否有运行中的作业，先取消作业
2. 检查该用户所属的组，先从组中移除
3. 确认 LDAP 管理员权限

### 4. 作业一直处于 PENDING 状态

**可能原因**:
- 所有节点都在忙碌
- 资源请求超过可用资源（CPU、内存、GPU等）
- 分区被禁用
- 用户没有该分区的使用权限

**解决方法**:
1. 查看节点状态，确认是否有空闲节点
2. 检查作业详情，确认资源请求是否合理
3. 检查分区状态是否为 UP
4. 检查用户是否在允许使用该分区的组中

### 5. 节点显示为 Down 状态

**可能原因**:
- 节点物理故障
- 网络连接问题
- Slurmd 服务未运行

**解决方法**:
```bash
# 登录到问题节点，检查 slurmd 服务
sudo systemctl status slurmd

# 重启 slurmd 服务
sudo systemctl restart slurmd

# 在管理节点上恢复节点
scontrol update nodename=node01 state=resume
```

### 6. 无法创建分区

**可能原因**:
- 节点名称不存在
- Slurm 配置文件权限问题
- Slurm 控制器服务异常

**解决方法**:
1. 确认节点名称拼写正确
2. 检查 Slurm 控制器服务状态：
```bash
sudo systemctl status slurmctld
```
3. 查看 Slurm 日志：
```bash
sudo tail -f /var/log/slurm/slurmctld.log
```

### 7. 页面显示空白或加载失败

**可能原因**:
- 会话过期
- 后端服务未启动
- 网络连接中断

**解决方法**:
1. 刷新页面并重新登录
2. 检查后端服务状态：
```bash
sudo supervisorctl status openhpc_webui
```
3. 查看应用日志：
```bash
sudo tail -f /var/log/openhpc_webui/error.log
```

### 8. 创建用户后无法提交作业

**可能原因**:
- Slurm 账户未同步
- 用户不在允许的组中

**解决方法**:
```bash
# 检查用户是否在 Slurm 账户系统中
sacctmgr show user username

# 手动添加用户到 Slurm
sacctmgr -i add user username account=dawn
```

### 9. 忘记管理员密码怎么办？

**解决方法**:

需要在 LDAP 服务器上重置密码：
```bash
# 使用 slappasswd 生成新密码的哈希
slappasswd

# 编辑 LDAP 配置或使用 ldapmodify 重置密码
ldappasswd -x -D "cn=admin,dc=acdiost,dc=com" -W -S "cn=admin,dc=acdiost,dc=com"
```

### 10. 如何查看系统日志？

**应用日志位置**:
```bash
# 访问日志
/var/log/openhpc_webui/access.log

# 错误日志
/var/log/openhpc_webui/error.log

# 实时查看
sudo tail -f /var/log/openhpc_webui/error.log
```

**Slurm 日志位置**:
```bash
# 控制器日志
/var/log/slurm/slurmctld.log

# 计算节点日志
/var/log/slurm/slurmd.log
```

**LDAP 日志**:
```bash
# 系统日志中的 LDAP 相关信息
sudo journalctl -u slapd
```
